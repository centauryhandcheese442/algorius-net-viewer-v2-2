## 🔍 Key Features
This version includes practical tools for network oversight:

* Device Discovery: The application scans your local router and identifies all hardware connected to your network.
* Availability Monitoring: The program sends signals to your devices to see if they remain active. You receive alerts if a device goes offline.
* Visual Topology: You can drag and drop icons to create a map of your network. This map shows how devices connect to each other.
* Reporting: The system creates logs of network uptime. You can review these logs to find patterns or track issues over time.
* Custom Alerts: You can set triggers for specific events. For example, the software sends a notification if a critical server stops responding.

## 🛠️ Using the Application
Once you launch the program, you see the main interface. Follow these steps to begin your first scan.

1. Locate the Tools menu in the top navigation bar.
2. Select the Network Scan command.
3. Enter your network IP range, such as 192.168.1.0/24, if the application does not detect it automatically.
4. Click the Scan button. 
5. Wait for the progress indicator to complete.
6. The application displays a list of found devices in the side panel. 
7. Drag these devices onto the blank workspace in the center to build your network map.
8. Right-click any device icon to view its properties and see current status information.

## 💡 Troubleshooting Common Issues
If you encounter problems, check these solutions:

* Application fails to launch: Ensure your Windows operating system is up to date. You might need to restart your computer.
* No devices appear in scans: Verify that your computer has a stable network connection. Check your local firewall settings to ensure they allow the software to scan the network.
* High memory usage: If the application feels slow, try limiting the number of devices you track at one time. Close other background programs that use high amounts of memory.
* Map errors: If you make a mistake while drawing diagrams, use the undo command in the Edit menu. You can also save your progress and restart the application if the view becomes cluttered.

## 🛡️ Privacy and Safety
This software runs locally on your PC. It does not send your network data to external servers. All information regarding your devices stays on your machine. You control exactly what the software scans and how it monitors your network.
